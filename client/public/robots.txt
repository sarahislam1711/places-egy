# Faceted/search views of the listings page — any /listings?query URL — are
# low-value variations of the base /listings page. They can render empty (soft
# 404s), they duplicate content across filter combinations, and they were
# showing up as "Redirect error" in Google Search Console because the SPA
# marks them noindex via JS after first render. Block the entire filter
# family so crawlers only see the clean /listings URL. Individual listing
# detail pages (/listings/{id}-{slug}) and the base /listings page stay
# fully crawlable.
Disallow: /listings?
# /projects?q=X are search-filter variants of the /projects hub — each
# renders the projects page filtered to one project. Google was crawling
# 90+ of these and correctly refusing to index them (all soft-duplicates
# of the base /projects). Blocking here saves crawl budget + declutters
# GSC's "not indexed" report.
Disallow: /projects?q=
